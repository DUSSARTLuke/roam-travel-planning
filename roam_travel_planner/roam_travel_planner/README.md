# Roam PWA

Application web progressive de planning de voyage, préremplie avec Londres (28/12/2026–03/01/2027).

## Publication gratuite avec GitHub Pages
1. Créez un dépôt GitHub public `roam-travel-planner`.
2. Ajoutez les fichiers de ce dossier à la racine.
3. Dans Settings > Pages, choisissez Deploy from a branch, branche `main`, dossier `/ (root)`.
4. Ouvrez l'URL GitHub Pages sur le Samsung avec Chrome, puis menu ⋮ > Installer l'application / Ajouter à l'écran d'accueil.

Les données sont stockées localement dans le navigateur. L'export JSON permet une sauvegarde manuelle. La synchronisation multi-appareils n'est pas incluse.
